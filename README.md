# Puffin Isle

A 3D multiplayer snowy-island hangout game for you and your friends.

- Real 3D world with a rotating camera (Q/E or the ⟲ ⟳ buttons, scroll to zoom, right-drag to spin)
- 10 places: Town, Cocoa Café, Night Club, Gift Shop, Ski Hill, Ski Lodge, Dock, Fishing Hut, Snowy Beach, Lighthouse
- Your own home: Igloo, Log Cabin or Ice Castle, 10 floors, 12 wall colors, 24 kinds of furniture you can place, move and rotate. Friends can visit.
- 13 quests from 7 characters (look for ❗ and ❓), a quest log (L), an objective tracker, XP and levels
- Live chat, emotes, dancing, snowball fights
- 3 minigames that earn coins: Sled Race, Ice Fishing, Cocoa Catch
- 11 wearable items and 12 feather colors

## Run it on your own computer
Install Node.js (18 or newer), then in this folder run:

    node server.js

and open http://localhost:3000

## Put it online (Render)
Upload all the files in this folder to a GitHub repository (there are no subfolders).
- Build command: `npm install`
- Start command: `node server.js`

No extra packages are needed.
